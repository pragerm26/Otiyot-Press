# Privacy Notice

**Status:** This document describes intended project principles, not a claim that every implementation detail has been independently audited. Review the current source code and network behavior before relying on any specific privacy guarantee.

## Purpose

Otiyot Press supports accessible Hebrew-language learning materials and publishing resources. Privacy is especially important when materials may be used by students, including minors or learners with disabilities.

## Data minimization

The project should collect only the information necessary for its functions. Do not submit identifiable student information, educational records, private communications, or sensitive personal details in public issues, pull requests, screenshots, or sample files.

## Local processing and external services

Do not assume that all processing is local or that the project makes no network requests. Actual behavior depends on the current implementation, browser, and any external resources used. Before using the project with sensitive material, review the source code and inspect network activity as appropriate.

## Third-party resources

The project may include fonts, text files, or other resources created by third parties. Their providers may have separate privacy practices and terms.

## Reporting a privacy concern

Report suspected privacy issues through the private reporting route described in [`SECURITY.md`](SECURITY.md). Avoid placing personal information in a public issue.

## Updates

This notice should be updated when the project's data handling, external integrations, or use cases materially change.
