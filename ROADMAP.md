# Roadmap

This roadmap describes possible areas of work, not guaranteed delivery dates or promises. Priorities may change based on testing and feedback.

## Documentation and project clarity

- [x] Explain the relationship between Otiyot Press and Otiyot+.
- [x] Add contribution, community, privacy, and security guidance.
- [ ] Document the current application workflow and supported browsers.
- [ ] Add screenshots or a short demonstration once the interface is stable.
- [ ] Document any build or local-server requirements after verifying them.

## Accessibility and publishing quality

- [ ] Test Hebrew right-to-left rendering across supported browsers.
- [ ] Check niqqud, punctuation, spacing, line breaks, and page boundaries.
- [ ] Collect feedback from educators and learners with different reading needs.
- [ ] Document known limitations and workarounds.

## Content and provenance

- [ ] Inventory texts, fonts, and other included assets.
- [ ] Record source, author/rights holder, and license for each third-party resource.
- [ ] Distinguish original project material from public-domain, licensed, and externally sourced material.
- [ ] Add a repeatable review process for textual accuracy.

## Development quality

- [ ] Establish a reproducible local development workflow.
- [ ] Add automated checks where useful.
- [ ] Add a release/versioning process once releases are made.

Suggestions are welcome through the repository issue tracker.
